StudyVault – Student Study Resource & Task Manager

StudyVault is a full-stack web application designed to help students organize and manage their online learning resources in one centralized platform. Instead of simply saving bookmarks or maintaining a separate to-do list, StudyVault connects each study resource with an actionable task, deadline, priority, and completion status.

Students can save useful tutorials, YouTube videos, GitHub repositories, documentation, research papers, and other educational resources, organize them by subject and category, and track what they actually need to do with each resource.

✨ Features
🔐 User Authentication – Secure registration and login with password hashing and session management.
👤 Private User Data – Each user can access and manage only their own resources and tasks.
📚 Study Resource Management – Add, edit, delete, and organize learning resources.
🔗 Automatic URL Title Fetching – Retrieves webpage titles using Python Requests and BeautifulSoup.
📝 Action-Based Tasks – Attach a specific study action to each resource.
📅 Deadline Tracking – Set deadlines for study activities and view upcoming tasks.
🎯 Priority Management – Organize tasks using Low, Medium, and High priorities.
🔄 Progress Tracking – Track resources as Not Started, In Progress, or Completed.
🔍 Search & Filtering – Search resources by title, subject, tags, tasks, and descriptions.
⭐ Favorites – Mark important resources for quick access.
🗄️ Archive & Restore – Archive completed or old resources without permanently deleting them.
🚫 Duplicate URL Detection – Prevent the same resource from being saved multiple times.
🌐 Link Health Checking – Check whether saved resources are still accessible.
📊 Personalized Dashboard – View resource statistics, subject distribution, progress, and upcoming deadlines.
📱 Responsive Interface – Designed to work across desktop, tablet, and mobile screens.
