StudyVault – Student Resource & Task Manager
Live App: https://harshnaik19.github.io/STUDY-VAULT/
GitHub Repository: https://github.com/harshnaik19/STUDY-VAULT
Tech Stack: JavaScript (ES6+), HTML5, CSS3, Python, Flask, Web Scraping, LocalStorage API

• Built and deployed a full-stack student study manager linking study materials with actionable tasks, target deadlines, priority levels, and completion tracking.
• Implemented student authentication (Login, Registration, Logout) with per-user data isolation and local storage persistence.
• Developed automated webpage title extraction using web scraping and duplicate URL prevention.
• Designed a dark-mode UI with live metrics counters, subject breakdown progress bars, and real-time multi-criteria filtering without page reloads.
