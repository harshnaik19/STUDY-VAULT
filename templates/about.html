About StudyVault & Demonstration Guide

Understand the core concept and run through the standard demonstration workflow.

Project Purpose

StudyVault is created for college students to bridge the gap between bookmarking study resources (websites, YouTube videos, GitHub repositories, documentation) and actually completing study actions. Unlike generic task managers, StudyVault enforces a direct link:

Study Resource
→
Action Item / Task
→
Target Deadline
→
Completion

Demonstration Flow Checklist

1
Open Dashboard: View total study resources, completed tasks, in progress items, subject breakdown counters, and upcoming deadline list.
2
Add a New Resource & Auto Title Fetch: Click "Add Resource", enter a URL such as https://flask.palletsprojects.com, click "Auto Title" (or let blur populate it). Notice BeautifulSoup automatically retrieves the page title.
3
Duplicate URL Detection: Re-enter an existing URL in the form; notice the warning banner stating "This resource has already been saved."
4
Set Task & Deadline: Attach a specific action (e.g. "Complete authentication module") and deadline date.
5
Live Search & Filter: On the Resources page, type in the search bar or select filters (Subject, Priority, Status) to instantly refine cards without reloading.
6
Mark Complete & Check Dashboard: Change status dropdown to "Completed". Return to Dashboard to see completion counters update live.
7
Star as Favorite & Archive/Restore: Star an item to view it in Favorites, or Archive an old resource and restore it from the Archived tab.
